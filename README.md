# Marlboro — A Visual History

A responsive editorial-style static website exploring Marlboro's visual identity and cultural history. This is an informational design project only; it does not sell or promote tobacco products.

## Run locally

Open `index.html` in a browser, or serve the directory with any static web server:

```bash
python3 -m http.server
```

The page includes an adult-age gate, responsive layouts, a visual timeline, and sections on the brand's history, identity, and legacy.
